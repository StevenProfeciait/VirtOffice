# Office worker GLB (optional)

Place a rigged character with seated and walking animation clips here:

```text
model.glb
```

The bundled `model.glb` is a 65-bone Quaternius-derived CC0 character with generated runtime
seated/working clips. Agents can select it with `"assetId": "office-worker-glb"`; the loader also
falls back safely if the file is removed. The original license text is preserved beside the model.

Run `scripts/install_cc0_assets.sh` for setup instructions. Record licence details in `docs/ASSET_CREDITS.md`.
